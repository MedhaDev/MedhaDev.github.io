Building the data pipeline for a 25-year prevention study.

The prevention studies at the Edna Bennett Pierce Prevention Research Center go back more than two decades. The data was never designed to be analyzed together: formats, variable names and missing-data codes changed depending on which year or cohort collected them.

I built the pipeline that brings all of it into one consistent structure, with checks that catch problems before investigators ever see the data.

One structure for 25 years of surveys

I designed research database schemas with field-level validation, branching logic and relational constraints, so files arriving in different formats from different years land in the same structure. Missing data is handled by one set of rules applied to every instrument, instead of each survey being patched by hand. So far the pipeline has standardized more than 250,000 survey records.

Checks instead of manual cleaning

Validation checks now run automatically across the center’s behavioral health studies. Investigators used to wait for data to be cleaned by hand before they could start analysis; now report turnaround is about 40% faster.

Keeping up with the research

I also built AWS-hosted Streamlit dashboards that pull from the Overton and OpenAlex APIs to track more than 10,000 published articles for the team.
